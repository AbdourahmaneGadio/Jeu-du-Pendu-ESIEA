# Jeu du Pendu ESIEA

Projet du jeu du pendu dans le cadre d'un projet scolaire

## Requis

Vous avez besoin d'avoir la librarie Raylib pour jouer au jeu.

Pour l'installer, consultez [le site de Raylib](https://www.raylib.com/).

### Exemple avec Debian/Ubuntu (instructions tirées du site de Raylib)

```
sudo apt install build-essential git
sudo apt install libasound2-dev libx11-dev libxrandr-dev libxi-dev libgl1-mesa-dev libglu1-mesa-dev libxcursor-dev libxinerama-dev

git clone https://github.com/raysan5/raylib.git raylib
cd raylib/src/
make PLATFORM=PLATFORM_DESKTOP
sudo make install
```

## Lancement

Allez dans le répertoire du jeu, ouvrez un terminal et exécutez ces instructions pour lancer le jeu :

```
chmod +x playGame.sh
./playGame.sh
```

Bonne partie !
